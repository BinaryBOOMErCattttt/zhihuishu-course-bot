浏览器与速度

默认使用本机 Edge。第一次使用需要登录一次，之后会保留登录状态。

怎么用

  1. 启动浏览器：点击控制台的「启动浏览器」，会打开一个独立的 Edge 窗口。
  2. 登录一次：如果未登录，点「登录」，学校/账号/密码会自动填好，你只需要完成图片验证码并点登录。登录状态会保留。
  3. 开始刷课：回到控制台点「开始刷课」。脚本会按课程列表逐门打开、翻页、答题、等待视频、处理验证码。
  4. 验证码：出现图片验证码时，右侧会弹出验证窗口，按提示顺序点击图片即可，脚本会继续。
  5. AI 答题：在设置里填 DeepSeek API Key。没有 Key 也能跑，简单题使用内置规则；复杂题建议配置模型。

注意

  • 脚本只操作你自己的账号，不修改课程内容。
  • 浏览器窗口可以最小化，但不要关闭；关闭后需要重新启动。
  • 遇到卡住会在日志里标红，并停在当前课程，方便你接手。
